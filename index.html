Working orchestration loop

  1. Build and save a checkpoint.
  2. Copy a node drop or broadcast payload.
  3. Open the provider tab and paste the payload manually.
  4. Paste the genuine response into Response Ingestion and select its source.
  5. Repeat, then copy the consensus packet back to the director AI.

What is fixed

Vault persistence, safe rendering, checkpoint autosave, Kimi dispatch, attributable response logs, JSON import/export, and mobile controls.

What is not claimed

No cross-provider zero-click injection, no fake synchronized status, and no embedded provider frames. Those require a separately installed and verified relay.
